# 심연 탈출 (THE ABYSS)

설치 없이 브라우저에서 하는 1인칭 멀티플레이 던전 탈출 게임.
방장이 방을 만들고 5자리 코드(또는 초대 링크)를 공유하면 친구들이 들어와요. 게임 판정은 방장 브라우저가, 연결은 PeerJS(P2P)가 맡아요.

- 실행: 정적 호스팅(GitHub Pages 등)에 그대로 올리거나, 로컬에서 `python serve.py` 후 http://localhost:8000
- 조작: WASD 이동 · 마우스 시점 · 좌클릭 공격 · Q/우클릭 스킬 · 1 물약 · F 상자/줍기 · Tab 가방 · [ ] 감도 · M 원시 입력 · ` 위장 화면
